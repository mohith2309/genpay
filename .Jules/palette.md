## 2024-05-24 - Accessibility for Custom Swipe Actions
**Learning:** Custom swipe gestures in Flutter (like the one used in `TransactionCard` with `GestureDetector` on horizontal drag) are not inherently accessible to screen readers. Standard `Dismissible` provides semantics out-of-the-box, but custom implementations require manual `Semantics` wrapping using `CustomSemanticsAction` to expose the swipe actions to users relying on accessibility tools. Also, dynamic labels in `CustomSemanticsAction` cannot use `const` and actions should be conditionally provided based on whether swipe actions are enabled.
**Action:** Always wrap custom gesture-based interactive elements (especially swipe-to-reveal items) in a `Semantics` widget. Map the hidden actions to `customSemanticsActions` so screen reader users can trigger them without performing the visual gesture. Ensure static labels use `const` for performance.
