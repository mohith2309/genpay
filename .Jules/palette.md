## 2024-06-13 - Make swipeable transaction card accessible and add haptic feedback
**Learning:** Custom gesture-based swipeable cards don't natively expose their actions to screen readers. Wrapping them in `Semantics` and using `CustomSemanticsAction` is necessary to make these hidden swipe actions discoverable and usable. Similarly, custom gestures lack default tactile feedback; explicitly adding HapticFeedback (like `lightImpact` for revealing, `mediumImpact` for destructive/major actions, and `selectionClick` for state toggles) bridges the gap and creates a more polished interaction.
**Action:** Always wrap custom `GestureDetector` based interactive components (like swipeable cards) in `Semantics` and map their actions using `CustomSemanticsAction`. Ensure to complement these custom gestures with appropriate `HapticFeedback` to mimic native system feel.
