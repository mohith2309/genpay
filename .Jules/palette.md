## 2025-05-15 - Enhancing Custom Swipe Actions with Semantics and Haptics
**Learning:** Custom drag-to-reveal components in Flutter (like the one in `TransactionCard`) are invisible to assistive technologies if they don't explicitly use the `Semantics` widget. Providing `customSemanticsActions` allows screen reader users to discover and trigger these actions without performing complex gestures. Additionally, pairing these interactions with `HapticFeedback` (light for snaps, medium/selection for actions) creates a more premium, tactile experience.
**Action:** When implementing custom gestures or hidden actions, always wrap the trigger with `Semantics` and provide `customSemanticsActions`. Use standardized haptic feedback: `lightImpact` for UI snaps/reveals, `mediumImpact` for destructive or heavy actions, and `selectionClick` for state toggles.
